## Indigenous Data Governance

::FaqAccordion

::Faq{value="1"}
The [Indigenous Data Network (IDN)](https://mspgh.unimelb.edu.au/centres-institutes/onemda/research-group/indigenous-studies-unit/indigenous-data-network) is a national initiative that supports Aboriginal and Torres Strait Islander communities in leading the design, governance, and use of data that reflects their cultural values, priorities, and knowledge systems.
#title
What is the IDN?
::

::Faq{value="2"}
The CARE and FAIR principles provide a framework for data management. FAIR focuses on reuse and openness, while CARE ensures ethical, people-oriented, and Indigenous-led governance.

#title
What are the FAIR and CARE principles?
::

::Faq{value="3"}
The Indigenous Data Network (IDN) defines Indigenous data as: 

Data generated, intentionally or not, by, about, or for Aboriginal and Torres Strait Islander people. Indigenous data refers to information, in any format or medium, collected, analysed, stored, and interpreted within the context of Indigenous individuals, collectives, populations, entities, lifeways, cultures, knowledge systems, lands, biodiversity, water and other resources. It includes data collected, used, or stored by any agency, department, laboratory, organisation, corporation, statutory body, university or research institute, conducted by, with, and about Indigenous people or people, and data that Indigenous communities have generated and maintained themselves. (Indigenous Data Network, 2024) 
#title
What is Indigenous Data?
::

::Faq{value="4"}
Indigenous data governance refers to the principles, practices, and systems by which Indigenous communities exercise control over the collection, ownership, management, and use of data relevant to them.
#title
What is Indigenous Data Governance?
::

::Faq{value="5"}
The IDN leads this project in partnership with the ARDC, leading universities, Aboriginal community-controlled organisations, government agencies, the GLAM sector and industry.

## Technical Concepts

::FaqAccordion

::Faq{value="1"}
Metadata is often said to be “data about data”. It is the contextual information that describes and gives information about other data.
#title
What is metadata?
::

::Faq{value="2"}
An ontology defines concepts, properties, and relationships to structure knowledge.
#title
What is an ontology?
::

::Faq{value="3"}
Resource Description Framework (RDF) is a W3C standard framework for modelling, exchanging, and linking data on the web.
#title
What is RDF?
::

::Faq{value="4"}
SPARQL is a query language used to retrieve and manipulate data stored in RDF format.
#title
What is SPARQL?
::

::Faq{value="5"}
A data commons is cloud-based infrastructure coupled with governance strategies and principles that allow a community to use, share, manage and analyse its data.
#title
What is a data commons?
::

::Faq{value="6"}
A catalogue is a detailed, organised inventory of an organisation's data assets, acting as a searchable repository that uses metadata to help users discover data.
#title
What is a catalogue?
::

::Faq{value="7"}
The IDN Catalogue Profile (IDN CP) is a specialised version - a 'profile' - of the general-purpose W3C Dataset Catalogue Vocabulary (DCAT). DCAT is used to "facilitate interoperability between data catalogues published on the Web". The IDN CP is used to do that but is tuned to best represent information about Indigenous people and their data. 

[Go to the Catalogue Profile Guide](https://idn-au.github.io/idn-catalogue-profile/resources/guidance.html)

What is the IDN catalogue profile?
::
